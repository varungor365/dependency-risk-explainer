# Security Policy

## Scope

Dependency Risk Explainer is a local-first, read-only advisory formatter. It does not install packages, execute repository code, authenticate to GitHub, or transmit project contents.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository when available. Otherwise contact the maintainer through the email listed on the GitHub profile. Do not include credentials, private source, or complete secret values in a report.

## Limitations

The tool is not a vulnerability scanner or a guarantee of package safety. Advisory data, package resolution, and exploitability require independent verification.
